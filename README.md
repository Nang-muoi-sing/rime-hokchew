# 福州话输入方案

配方： ℞ **hokchew**

[Rime](https://rime.im) 福州话输入方案

- 榕拼输入法：汉字 (`hokchew`)：使用榕拼方案击出福州话汉字
- 榕拼输入法：拼音 (`hokchew_yngping`)：使用榕拼方案击出榕拼手写形式
- 榕拼输入法：教罗 (`hokchew_roma`)：使用转写方案击出福州话教会罗马字

## 简繁切换

`hokchew` 使用 OpenCC 的 `t2s.json` 输出简体；关闭转换时输出繁体。可在 Rime 方案选单中选择“繁體 / 简体”，选择会通过标准 `simplification` 选项保存；可按 `Control+Shift+4` 或 `Control+Shift+8` 快速切换。
